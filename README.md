# **窗体模式**
* **课表联动模式**：搭配蒹葭时钟校园版（JJClock-Schedule_Version）5.0及更高版本使用，可实现上课自动隐藏、下课自动弹出，窗体位置固定于屏幕中上方。
* **[默认]桌面模式**：贴在桌面上，不会覆盖内容，窗体位置可随意拖动。


# **OMN万用键操作**
***位于窗体左上角，默认为软件“365”图标***
* **单击**：切换正常/mini模式，≈一键最小化，mini模式下图标可任意拖动
* **双击**：退出软件
* **右键(触屏长按)**：切换窗体模式
